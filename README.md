## setting up environment (in terminal)
1.  create a virtual environment 
>python -m venv .venv
2.  active virtual environment
>source .venv/bin/activate
3. to install libraries / dependencies, first a requirement.txt file
4. add openai, streamlit, python-dotenv to requirements.txt file
5. install dependencies by referring to requirements.txt file
>pip install -r requirements.txt
6. create a .env file
7. ensure .evn file is grayed out (git ignored) - if not edit。gitignore to include .env
